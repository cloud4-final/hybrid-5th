# 온프레미스 VM 생성 코드

KVM·libvirt 환경에서 Ubuntu cloud image와 cloud-init을 사용해
VM을 생성하기 위한 Ansible 공통 플레이북입니다.

## 파일 구성

- `create-vm-common.yml`: VM 생성 공통 플레이북
- `vm-vars.yml`: 문서용 변수 예시
- `templates/`: cloud-init 설정 템플릿

## 실행 전 확인

- KVM·libvirt와 필요한 명령, 인벤토리와 SSH 공개키를 별도로 준비합니다.
- 예시 변수는 실제 환경에 맞게 검토해야 합니다.
- 저장 장치 경로와 이미지 SHA-256이 코드에 고정돼 있어 대상 환경에서 확인해야 합니다.
- 생성 사용자에게 비밀번호 없는 sudo 권한을 주는 설정이 있으므로 팀 정책을 확인해야 합니다.

## 검증 범위

- 기존 VM 구축에 사용한 코드를 정리했습니다.
- 새 환경에서 전체 재구축 시험은 아직 하지 않았습니다.
- Data VM의 별도 데이터 디스크와 망 분리 후 전체 구성은 별도 검토가 필요합니다.
